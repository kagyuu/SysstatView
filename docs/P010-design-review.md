## 2. 検出した矛盾点

### 矛盾点 #1 — グラフ X 軸の方式が両立しない 【重要度: 高】

| 項目 | 内容 |
| --- | --- |
| 所在A | `docs/P001-requirement.md` §2.1(a): 「サンプル時刻は厳密な等間隔ではない…グラフは固定間隔を仮定せず**実測時刻に対してプロットする**」 |
| 所在B | `docs/P002-frontend-spec.md` §3.3: 「X 軸 = 採取時刻。**等間隔を仮定せず実測時刻に対してプロットする**」 |
| 所在C | `docs/P007-impl-direction/U007-frontend-graph-sc02.md` U007-T3: 「X 軸は**カテゴリ軸**として `timestamps` を用いる。等間隔を仮定した生成をしない」 |
| 矛盾の内容 | **カテゴリ軸は、値の実際の間隔にかかわらず各点を等間隔に描画する。** したがって所在C の実装方針は、所在A・B が要求する「実測時刻に対するプロット」を満たさない。所在C の後半「等間隔を仮定した生成をしない」は、時刻配列を等間隔で*生成*しないという意味では正しいが、*描画*が等間隔になる点を解消していない |
| なぜ重要か | 本システムのサンプル間隔は実測で 00:10:09 / 00:20:12 / 00:30:03 と揺らぐうえ、収集が停止した期間があれば大きな欠測が生じる。カテゴリ軸ではその欠測が視覚的に潰れ、**連続して収集されていたかのように見える**。性能ログの閲覧という用途において、これは誤読を招く |
| 差し戻し先 | **P002** (描画方式は画面仕様の担当範囲) および **P007** (実装指示) |
