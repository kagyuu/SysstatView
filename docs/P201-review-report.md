## 3. NOT RUN の扱いについての明示

**NOT RUN を PASS として扱っていない。** 本フェーズは「すべて合格」を宣言できる状態ではなく、正確には**「実行できたテストはすべて合格し、実行できないテストが 11 件残っている」**状態である。

| 未実行 | 原因 | 解消に必要なこと |
| --- | --- | --- |
| T002 (2 経路の一致、8 件) | `sadf` が無く導入不可 | sysstat が入る環境での実行 |
| A005 (コンテナ構成、全項目) | Docker が無い | Docker が使える環境での実行 |
| A004 項目 4 (初回グラフ描画時間) | ブラウザ計測手段が無い | 実ブラウザでの計測 |
| `sa24` の 200 応答 | `sadf` が無い | 同上 (T002 と同じ) |
| シンボリックリンクの 404 | Windows で作成に管理者権限が必要 | 管理者権限または Linux 環境 |

* これらは**アプリケーションの欠陥ではなく、実行環境の制約**である。`SKILL.md` の「テストを実行できなかった状態」に該当し、原因を切り分けたうえで `docs/ArchitectureHandbook.md` §9 に記録済みである。
* **とくに T002 と A005 は、`sa` (バイナリ) 経路を実地で検証する唯一の機会**であり、未実行のまま納品される。この点は P302 の「未整備事項」に必ず引き継ぐこと。
