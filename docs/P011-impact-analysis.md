### 影響を受ける箇所

| 1-b | `docs/P007-impl-direction/U007-frontend-graph-sc02.md` | U007-T3 実装内容 | 「X 軸はカテゴリ軸として `timestamps` を用いる」 | **誤り。**線形軸へ変更する |

### 技術的な検討

* Chart.js でカテゴリ軸以外を選ぶ場合の選択肢は 2 つある。
  1. **時間軸 (`type: 'time'`)**: 日時を直接扱えるが、**date adapter (`chartjs-adapter-date-fns` など) の追加依存が必要**になる。
  2. **線形軸 (`type: 'linear'`)**: X 値を epoch ミリ秒の数値として与え、目盛りのラベルだけを `callback` で `HH:mm` に整形する。**追加依存が不要。**
* 本システムは 1 ファイル = 1 日分であり、目盛りを時刻表示にできれば十分である。追加依存を増やさない **選択肢 2 (線形軸)** を採る。
* この変更は `docs/P005-impl-plan.md` §1.2 の依存関係表 (Chart.js + ng2-charts) を変えない。

### 波及の有無

* API 契約: **変わらない** (1-d)。
* 要求: **変わらない** (1-e)。
* バックエンド: **影響なし** (1-f)。
* したがって修正は P002 §3.3 と P007 U007 に閉じる。
