| テストID | 単体・P008 で代替できない理由 |

## 実行環境の前提と、実行できないテスト

`docs/P006-test-plan.md` §6.2 / §6.3 のとおり、この開発環境には **`sadf` と Docker が無い**。

| テストID | 現環境での実行可否 |
| --- | --- |
| A001 | **実行可能** (`sar` を選択する経路で通す) |
| A002 | **実行可能** — むしろこの環境の実態がそのまま検証条件になる |
| A003 | **実行可能** (ローカルプロセスとして起動・停止・再起動する) |
| A004 | **一部実行可能** (API の応答時間は測定可。ブラウザ描画時間は測定手段が無ければ NOT RUN) |
| A005 | **NOT RUN** (Docker が無いため。合格として扱わない) |

* **NOT RUN を PASS として記録しない。** 何を実行し何を実行できなかったかをテスト記録に明示する。
